# ASL Sign Language Recognition System

## Overview

This project is an AI-based system for real-time recognition of American Sign Language (ASL) using computer vision and deep learning.

It allows users to detect hand gestures, convert them into text, and interact through a web application.

---

## Architecture

- Frontend: React + MediaPipe (hand tracking)
- Backend: FastAPI (API & inference)
- Model: CNN (Keras) for gesture classification

---

## Technologies

- Python, FastAPI
- React.js
- TensorFlow / Keras
- MediaPipe
- OpenCV

---

## Features

- Real-time ASL gesture recognition
- Alphabet classification (A–Z)
- Sentence construction
- Translation and text-to-speech
